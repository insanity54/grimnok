## Dev

### Getting started

Install deps

    devbox install

Start pg

    devbox services up

Init db

    initdb

Create db user

    createuser --interactive

Create nakama db

    createdb nakama

Once nakama is running, go to http://localhost:7351. The default creds are admin:password
